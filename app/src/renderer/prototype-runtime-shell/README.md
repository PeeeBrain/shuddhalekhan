# Runtime shell visual-system prototype

> **Throwaway prototype for a Wayfinder decision. Do not promote this code directly to production.**

## Question

Which visual system, geometry, hierarchy, and motion model should the persistent runtime shell use across recording, processing, Agent status/streaming, approval, completion, and failure?

## Run

From `app/`:

```powershell
bun run prototype:runtime-shell
```

Open `http://127.0.0.1:4173/`. Use the floating arrow switcher or `?variant=A`, `?variant=B`, and `?variant=C`.

## Variants

- **A — Morphing capsule:** preserves the current pill as the visual seed, then unfolds into a conventional restrained card.
- **B — Command rail:** gives every surface a persistent semantic rail and a denser, more operational hierarchy.
- **C — Quiet stack:** separates a compact activity marker from a calm content sheet and uses the most progressive disclosure.
- **D — Orbit capsule:** keeps the production Dictation pill exactly, then gives Agent Mode an attached orbit and horizontal capsule that grows into a connected action surface.
- **E — Agent dock:** keeps the production Dictation pill exactly, then turns Agent Mode into an asymmetric command capsule with a persistent pill-like dock beneath richer states.

The control deck covers all eight surface families, transition/preemption trials, long-content overflow, compact display clamping, simulated 100–150% DPI, reduced motion, live-region intent, and deliberate activation of interactive surfaces.
